# Charte Graphique – Saviora IA

## 1. Identité et Philosophie
**Saviora IA** incarne l'excellence, la clarté et l'orientation stratégique dans le foisonnement des technologies d'intelligence artificielle.
L'identité visuelle puise son inspiration dans l'élégance éditoriale européenne et les constellations numériques : un repère de confiance pour les professionnels, créateurs et curieux du numérique francophone.

## 2. Palette de Couleurs Officielles

| Nom de Couleur | Code HEX | Usage Principal | Ratio recommandé |
|---|---|---|---|
| **Bleu Nuit** | `#0B1B3A` | Toile de fond, surfaces principales, structure | 60% |
| **Bleu Profond** | `#12305F` | Cartes secondaires, bordures, contrastes | 30% |
| **Or Saviora** | `#D4AF37` | Accents de haute intention, boutons primaires, étoiles de note | 10% |
| **Ivoire Numérique** | `#F8F5EC` | Typographie principale, titres, contrastes clairs | Support texte |
| **Bleu Nuit Profond** | `#081226` | Fond d'écran global (canvas bas) | Fond immersif |
| **Gris Minéral** | `#94A3B8` | Métadonnées discrètes, séparateurs de texte | Textes secondaires |

## 3. Typographie
- **Titres & En-têtes** : *Poppins* (600 SemiBold / 700 Bold) ou *Plus Jakarta Sans*.
- **Corps de texte** : *Plus Jakarta Sans* / *Poppins* (400 Regular / 500 Medium), interligne aéré (1.5 - 1.7), mesure 65-75 caractères.
- **Données, Tarifs & Chiffres** : Tabular numerals (`font-variant-numeric: tabular-nums`).

## 4. Règles d'usage et Anti-Slop
- Aucun encadrement pillule abusif pour les métadonnées statiques : utiliser des séparateurs typographiques discrets (`·`, `/`).
- Les statuts de vérification sont clairs et véridiques, accompagnés de dates réelles (AAAA-MM-JJ).
- Les boutons d'action utilisent des libellés fonctionnels sans jargon obscur : "Consulter le site officiel", "Comparer", "Ajouter aux favoris".
